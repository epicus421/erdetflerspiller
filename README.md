# erdetflerspiller
## deterflerspiller

A multiplayer mod for **erdetspill**, adding online/local multiplayer functionality to the original game.
-Works best with 2 people, but supports up to 4 people, bugs may occur

---
### ⚠️ Disclaimer
This is an unofficial fan-made modification. It is not affiliated with or endorsed by the original developers of **erdetspill**. Use at your own risk.
---
## Installation

This mod works by replacing the game's compiled data file (`.pck`) with a modified version. Follow the steps below carefully.

### 1. Locate your game files via Steam

1. Open **Steam** and go to your **Library**.
2. Right-click on **erdetspill** and select **Properties**.
3. Go to the **Installed Files** tab.
4. Click **Browse...** to open the game's local installation folder.

### 2. Back up the original `.pck` file

1. In the game folder, locate the original `.pck` file (it should share the same name as the game's executable, e.g. `erdetspill.pck`).
2. **Rename** this original file instead of deleting it — for example, rename it to:
   ```
   erdetspill_original.pck
   ```
   This keeps a backup so you can always restore the vanilla game later if you want to.

### 3. Install the mod

1. Download the modded `.pck` file from this repository.
2. Copy the downloaded `.pck` file into the same game folder.
3. Make sure it matches the **original** filename the game expects (`erdetspill.pck`).
4. Launch the game through Steam as normal.

### 4. Restoring the original game

If you want to go back to the unmodded game at any point:

1. Delete (or move elsewhere) the modded `.pck` file.
2. Rename `erdetspil_original.pck` back to its original name (`erdetspill.pck`).

---

## Notes

- Always keep a backup of the original `.pck` file before replacing it.
- If the game updates via Steam, it may overwrite the modded file - the mod is limited to specific versions of the game.
- Report bugs or issues via the [Issues](https://github.com/epicus421/erdetflerspiller/issues) tab on this repository.
